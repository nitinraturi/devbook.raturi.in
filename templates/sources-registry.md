# Sources Registry

Every source cited anywhere in <project> lives here, once, with an ID. Research docs and pages cite by ID.

**Status meanings**
- **Verified** — title, authors, venue and year checked against an index record or the publisher, and the cited finding checked against the abstract or full text.
- **Verified (details to confirm)** — record and finding checked; some bibliographic detail (volume, pages, full author list) still to confirm before the page goes live.
- **Verified via secondary** — finding seen in a reputable secondary source that cites this work. Read the primary before relying on details. Never the sole support for a High-certainty claim.
- **To verify** — do not publish any claim that depends on it.

## Adding a source
1. Find the record in an authoritative index (PubMed, Crossref, the publisher, official documentation).
2. Confirm title, all authors, venue, year, volume, pages, DOI or stable URL.
3. Read at least the abstract; read the full text if it drives a recommendation.
4. Add a row with the next ID, status, date checked and a one-line note in your own words.
5. Never reuse or renumber IDs. If a source is withdrawn or found wrong, mark it **Retracted/Removed** and update every doc citing it.

AI-suggested citations are unverified until a human has found the real record.
