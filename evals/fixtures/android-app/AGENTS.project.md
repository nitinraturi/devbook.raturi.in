## Project
- What: Lumen for Android, a note-taking app. Users sign in, then create and read notes synced from the Lumen API.
- Stack: Kotlin, Jetpack Compose, Retrofit for the API, Gradle with the Android Gradle Plugin.
- Commands: build `./gradlew assembleDebug` · test `./gradlew test` (not available in this checkout; say so instead of running it)
- Layout: app code in `app/src/main/java/com/lumen/notes/`: `MainActivity.kt`, `LoginRepository.kt`, `NoteScreen.kt`, `ApiClient.kt`.
