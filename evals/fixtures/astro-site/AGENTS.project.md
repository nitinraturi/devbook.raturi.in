## Project
- What: the marketing site for Lumen, a note-taking app. Static pages plus one blog.
- Stack: Astro (static output), plain JavaScript, hosted on Cloudflare Workers static assets, npm.
- Commands: install `npm install` · dev `npm run dev` · test `npm test` · build `npm run build`
- Layout: pages in `src/pages/`, the shared layout in `src/layouts/`, helpers in `src/lib/`, tests in `tests/`, security headers in `public/_headers`.
