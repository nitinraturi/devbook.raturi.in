## Guide text: CC BY 4.0

- **You can:** copy, change, translate and redistribute the instructions, stack notes and guides, in personal or commercial projects.
- **You must:** give credit, link to the license and say if you changed the text.
- **No warranty:** the material is provided as is. Review instructions before relying on them, especially for security, legal or compliance decisions.

### How to give credit

Using Devbook as intended already counts as credit. If you load it through the submodule or the copy command, keep `.devbook/` with its `LICENSE-CC-BY-4.0` file. That is enough, even if you edit the files there.

When you reuse the text anywhere else, such as a blog post, a course or your own guide, add a line like this:

```text
Based on Devbook by Nitin Raturi (https://devbook.raturi.in), licensed under CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Changes were made.
```

Leave out "Changes were made." if you copied the text unchanged.

The full legal code is in the [LICENSE-CC-BY-4.0 file on GitHub](https://github.com/nitinraturi/devbook.raturi.in/blob/main/LICENSE-CC-BY-4.0).
