## Guide text: CC BY 4.0

- **You can:** copy, change, translate and redistribute the skills and guides, in personal or commercial projects.
- **You must:** give credit, link to the license and say if you changed the text.
- **No warranty:** the material is provided as is. Review instructions before relying on them, especially for security, legal or compliance decisions.

### How to give credit

Using Devbook as intended already counts as credit. Installed skills carry `license: CC-BY-4.0` and their source in their frontmatter; keep that, even if you edit them.

When you reuse the text anywhere else, such as a blog post, a course or your own guide, add a line like this:

```text
Based on Devbook by Nitin Raturi (https://devbook.raturi.in), licensed under CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Changes were made.
```

Leave out "Changes were made." if you copied the text unchanged.

The full legal code is in the [LICENSE-CC-BY-4.0 file on GitHub](https://github.com/nitinraturi/devbook.raturi.in/blob/main/LICENSE-CC-BY-4.0).

## Templates and code: MIT-0

The bootstrap prompt writes the core block into your own `AGENTS.md`, and the hooks and settings it writes are yours too, so none of them need a notice. The same applies to the catalog, the scripts, the evals and the site's code: you can copy, change and sell them without credit.

The vendor skills in the catalog keep their own licences, shown on each source; Trail of Bits' skills, for example, are CC BY-SA 4.0.
