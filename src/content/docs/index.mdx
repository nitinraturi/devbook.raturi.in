  <h3 class="dvb-flow-subhead">Why use it</h3>
  <div class="dvb-home-layer-grid">
    <article>
      <h3>Same standard in every chat</h3>
      <p>Security, testing and accessibility rules apply without you repeating them in each prompt.</p>
    </article>
    <article>
      <h3>Small and cheap</h3>
      <p>Only what a task needs is loaded, and the always-loaded part is the same every time, so providers can cache it.</p>
    </article>
    <article>
      <h3>Versioned and yours</h3>
      <p>Devbook changes only when you update to a newer version from <code>main</code>, and every update is a diff you review. Your project rules override it where they say so.</p>
    </article>

<section class="dvb-quick-start" id="setup" aria-labelledby="setup-title">
  <div class="dvb-home-section-heading">
    <div>
      <p class="dvb-home-eyebrow">New or existing project · about a minute</p>
      <h2 id="setup-title">Set up with one prompt</h2>
    </div>
    <a class="dvb-home-text-link" href="/start-here/how-it-works/">New to this? How Devbook works <span aria-hidden="true">→</span></a>
  </div>

  <p class="dvb-quick-start-intro">Open your project in Claude Code or VS Code Copilot agent mode, with file editing and terminal access turned on. Paste this prompt. The assistant adds Devbook at <code>.devbook/</code>, either as a git submodule (the default) or as copied files (change <code>Method</code> to <code>copy</code>). It then picks the files your project needs and connects them. It does not commit anything.</p>
  <Code code={setupPrompt} lang="text" title="Paste into Claude or Copilot" />
  <ol class="dvb-quick-start-notes">
    <li><strong>Review.</strong> Check the new <code>AGENTS.md</code>, <code>CLAUDE.md</code> and <code>.github/copilot-instructions.md</code>, then fill in any TODOs about your project.</li>
    <li><strong>Commit.</strong> Commit those files and the <code>devbook-*</code> links in <code>.claude/</code> and <code>.github/instructions/</code>, along with <code>.devbook</code>, plus <code>.gitmodules</code> for a submodule. Then start a new chat so the instructions load.</li>
    <li><strong>Use it.</strong> Keep working as before. <a href="/start-here/using-devbook/">Use Devbook day to day</a> covers your own rules, checks and troubleshooting.</li>
    <li><strong>Stay current.</strong> Setup takes the latest <code>main</code>, and <code>.devbook/VERSION</code> records its version number. Devbook changes in your project only when you update. Ask "Is Devbook up to date?" and the assistant compares your version with <code>main</code>, summarises the changelog and updates when you agree. With the <a href="/start-here/enforcement-kit/">enforcement kit</a>, Claude Code tells you when a newer version is out. See <a href="/start-here/using-devbook/#keep-it-up-to-date">Keep it up to date</a>.</li>
  </ol>
</section>
