  <p class="dvb-quick-start-intro">Open your project in Claude Code or VS Code Copilot agent mode, with file editing and terminal access turned on. Paste this prompt. The assistant adds Devbook at <code>.devbook/</code>, either as a git submodule (the default) or as copied files (change <code>Method</code> to <code>copy</code>). It then picks the files your project needs and connects them. It does not commit anything.</p>
  <Code code={setupPrompt} lang="text" title="Paste into Claude or Copilot" />
  <div class="dvb-quick-start-notes">
    <p><strong>1. Review.</strong> Check the new <code>AGENTS.md</code>, <code>CLAUDE.md</code> and <code>.github/copilot-instructions.md</code>, then fill in any TODOs about your project.</p>
    <p><strong>2. Commit.</strong> Commit those files along with <code>.devbook</code>, plus <code>.gitmodules</code> for a submodule. Then start a new chat so the instructions load.</p>
    <p><strong>3. Use it.</strong> Keep working as before. <a href="/start-here/using-devbook/">Use Devbook day to day</a> covers your own rules, checks and troubleshooting.</p>
    <p><strong>4. Stay current.</strong> Devbook follows <code>main</code>, with no version pins. To update a submodule, run <code>git submodule update --remote .devbook</code>. For a copy, run the download command again.</p>
