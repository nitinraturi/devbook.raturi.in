  <div class="dvb-quick-start-notes">
    <p><strong>1. Paste the prompt.</strong> The assistant inspects your project and adds or reuses Devbook pinned to <code>v1.0.0</code>. Already have a submodule? It checks that first.</p>
    <p><strong>2. Review the setup.</strong> Design principles, coding standards, security and done criteria load in every Claude and Copilot session, and a CI check catches drift. Existing docs are kept; unknowns stay as questions.</p>
    <p><strong>3. Start a new chat.</strong> After reviewing the changes, open a fresh chat and ask for your next task. Your existing stack and hosting stay unchanged.</p>
