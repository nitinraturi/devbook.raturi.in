  <p class="dvb-quick-start-intro">Open your project in Claude Code or VS Code Copilot agent mode, with file editing and terminal access turned on. Paste this prompt. The assistant adds Devbook at <code>.devbook/</code>, either as a git submodule (the default) or as copied files (change <code>Method</code> to <code>copy</code>). It then picks the files your project needs and connects them. It does not commit anything.</p>
  <Code code={setupPrompt} lang="text" title="Paste into Claude or Copilot" />
  <ol class="dvb-quick-start-notes">
    <li><strong>Review.</strong> Check the new <code>AGENTS.md</code>, <code>CLAUDE.md</code> and <code>.github/copilot-instructions.md</code>, then fill in any TODOs about your project.</li>
    <li><strong>Commit.</strong> Commit those files and the <code>devbook-*</code> links in <code>.claude/</code> and <code>.github/instructions/</code>, along with <code>.devbook</code>, plus <code>.gitmodules</code> for a submodule. Then start a new chat so the instructions load.</li>
    <li><strong>Use it.</strong> Keep working as before. <a href="/start-here/using-devbook/">Use Devbook day to day</a> covers your own rules, checks and troubleshooting.</li>
    <li><strong>Stay current.</strong> Setup pins the newest dated release, such as <code>v2026.11.02</code>, so Devbook changes only when you upgrade. With the <a href="/start-here/enforcement-kit/">enforcement kit</a>, Claude Code tells you when a newer one is out. Read the changelog, then move to the new tag as described in <a href="/start-here/using-devbook/#keep-it-up-to-date">Keep it up to date</a>.</li>
  </ol>
</section>
