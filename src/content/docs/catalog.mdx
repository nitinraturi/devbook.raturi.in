Every source the bootstrap prompt may install. Each is maintained by the vendor of the platform it covers and pinned to a release, a commit or Anthropic's official marketplace, except Devbook's own skills, which track `main`. The list comes from [`catalog/sources.json`](https://github.com/nitinraturi/devbook.raturi.in/blob/main/catalog/sources.json), the same file the prompt is built from, in the same groups.

<Catalog />

## How a source gets in, and out

A source gets in when its vendor maintains it, it covers code quality for a common stack, and it doesn't touch deploys or CI. "Official" means Anthropic's `claude-plugins-official`, which pins the third-party plugins it lists and updates them automatically; the prompt reads every other source in full at its pinned ref before it installs it. An automated check opens a pull request each week for every source with a new release or commit, and the maintainer reads the upstream diff before merging. A source is retired when its vendor drops it, when it takes over deploys, when it fetches instructions at run time, or when the [measured evals](/evals/) show it no longer helps.
